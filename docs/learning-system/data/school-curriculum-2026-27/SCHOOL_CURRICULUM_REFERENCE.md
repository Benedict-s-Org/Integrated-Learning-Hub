This file is the **major curriculum reference** for the Learning System (DEC-20261105-01). Grade, teaching order, and grammar targets are taken from here. [`grammar-pacing.json`](./grammar-pacing.json) is the same map for code. It is not a micro-skill list, not a question bank, and not an automatic taught tick. Product rules (set size, attempts, weakness, assignments) stay in the Learning System master spec.

The file `HK_Primary_Grammar_24_Stage_Curriculum_EN.xlsx` is an external Hong Kong primary curriculum guide. It can be read for territory wording. It does not place a structure in a grade at this school.

## First-introduction map (for skill linking)

Use this when linking a micro-skill to a school year. The grade is the **first** year this curriculum teaches that structure. Later years may revise it. An Excel stage code is an external-guide note and does not move the year.

| Structure family | First taught |
|------------------|--------------|
| `This is` / `Who is`; simple present `like`; present continuous now; `in/on/under`; `a/an`; `would like`; o’clock / half past; `can` ability; `will` invitation; appearance `is/has`; `May I have` | P1 |
| `There is/are`; habitual present; simple past narrative; `when`; `Let’s` / `should`; possessives; `if`; `will` plans; `because`; sequencing words; `How much`; `How many`; `by` + transport | P2 |
| Past continuous + `until`; `Are there any`; `good at` + gerund; `use … to`; `must`; relative `who` (detail); ordinal dates; `keep` + gerund; `suggest that … should` | P3 |
| `How often` and frequency; `each other`; comparative and superlative; `too/either`; `both`; quantifiers `plenty of/a few/a little/enough/too many/too much/more/fewer/less`; `should` advice; `be going to`; `Shall we` / `How about` + gerund | P4 |
| `How far` / `How long does it take`; `Could you`; `could` past ability; `by` + reflexive; `used to`; present perfect with `yet/just/already/ever/never`; `for` / `since`; indefinite pronouns; `whose`; past continuous at a clock time; `while` | P5 |
| Relative `who/which/where`; first and second conditional; `so that`; `although`; `as … as`; `unless`; phrasal verb + preposition; passive; `since` for reason; `therefore`; reported `asked me to`; `ought to`; `would rather`; `either … or` / `neither … nor` | P6 |
